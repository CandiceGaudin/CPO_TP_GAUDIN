# CPO_TP_GAUDIN

Travail académique réalisé en binôme à l’EPF en 2024.

Ce dépôt regroupe plusieurs travaux pratiques réalisés en Java avec NetBeans. Ils m’ont permis de découvrir progressivement les bases du langage et de la programmation orientée objet.

## Contenu du dépôt

- **TP0** : premiers programmes, saisie utilisateur et calculs simples
- **TP1** : manipulation de nombres, convertisseur, statistiques et jeu *Guess My Number*
- **TP2** : création de classes et d’objets, méthodes, tableaux et relations entre objets
- **TP3 Heroic Fantasy** : utilisation de l’héritage avec des personnages et plusieurs types d’armes
- **Première interface graphique** : découverte d’une interface simple avec Java Swing

## Compétences travaillées

- Structures conditionnelles et boucles
- Méthodes et saisie utilisateur
- Classes, objets et constructeurs
- Tableaux et listes
- Relations entre objets
- Héritage
- Première approche des interfaces graphiques

## Technologies utilisées

- Java
- NetBeans
- Git et GitHub

Ce dépôt correspond à des exercices d’apprentissage. Il présente ma progression pendant le semestre et ne constitue pas une application finalisée.
